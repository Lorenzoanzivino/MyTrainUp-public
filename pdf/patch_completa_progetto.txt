# FitPlanner - Gestionale Schede di Allenamento

**FitPlanner è una piattaforma Web Full-Stack progettata per ottimizzare il flusso di lavoro tra Personal Trainer e Cliente. Non è solo un visualizzatore di schede, ma uno strumento di lavoro attivo con autenticazione sicura, timer integrati, feedback in tempo reale e interfaccia responsive.**

**La versione attuale introduce un sistema di Login sicuro (JWT), un'interfaccia Dark Mode moderna e una gestione modulare dei componenti.**

### ⚙️ Tecnologie Utilizzate

- Backend: Python 3, Flask (API REST), SQLite (Database Relazionale).

- Sicurezza: PyJWT (Gestione Token JSON Web Token per autenticazione e ruoli).

- Frontend: React.js (Vite), Tailwind CSS (Design System Mobile-First), Lucide React (Icone).

- Networking: Fetch API con supporto CORS, ottimizzato per test su rete locale (Mobile).

[⬆️ Torna su](#-Indice)

---

### 🏗️ Architettura del Progetto

Il progetto segue un'architettura Client-Server separata:

- **/backend**: Server Python che espone API RESTful. Gestisce l'autenticazione, la logica di business e la persistenza dei dati su SQLite.

- **/frontend**: Single Page Application (SPA) in React.
    - TrainerDashboard: Area amministrativa desktop-oriented per la gestione.
    - ClientArea: Interfaccia mobile-first per l'esecuzione dell'allenamento.

### ✨ Funzionalità Chiave

- 🔐 Sicurezza & Accessi

    - Login Multi-Ruolo: Accesso distinto per Trainer (Admin) e Clienti.

    - Protezione Rotte: Reindirizzamento automatico se non loggati.

    - Creazione Utenti "Chiavi in Mano": Il Trainer crea i clienti e il sistema genera automaticamente Username (nome_cognome) e Password (fit123).


- 🏋️‍♂️ Per il Trainer (Dashboard Avanzata)

    - Workout Builder 2.0 (CRUD Completo):

        - Creazione e Modifica di schede esistenti.

        - Interfaccia a griglia dinamica: aggiungi/rimuovi esercizi e singole serie con un click.

        - Doppia Nota: Scrivi istruzioni tecniche specifiche per ogni serie (es. "Fase eccentrica lenta") che il cliente vedrà ma non potrà modificare.

    - Gestione Cartelle:

        - Organizza le schede per Ciclo (es. "Ipertrofia", "Settembre") o Tipologia.

        - Crea ed elimina cartelle direttamente dal Builder.

    - Monitoraggio Clienti:

        - Visualizza tutte le schede assegnate a un cliente.

        - Leggi i feedback lasciati dal cliente accanto ai dati tecnici.

        - Modifica o elimina schede obsolete.


- 📱 Per il Cliente (Area Allenamento Mobile)

    - Visualizzazione Ottimizzata:

        - Le schede sono presentate in modo chiaro, esercizio per esercizio.

        - Distinzione visiva tra i dati tecnici (Reps, Kg), le istruzioni del Trainer (blocco info) e i propri feedback.

    - ⏱️ Recovery Timer Intelligente:

        - Il tempo di recupero (es. "90") è un bottone interattivo.

        - Cliccandolo, parte un countdown visivo (Arancione -> Viola -> Verde).

        - Supporta Pausa e Stop.

    - Feedback Granulare:

        - Campo note dedicato per ogni singola serie per segnare sensazioni o carichi effettivi.

### 🛠️ Installazione e Setup (Da Zero)

Se scarichi questo progetto su un nuovo computer, segui questi passi una sola volta.

1. Configurazione Backend
```bash
cd backend
# Crea l'ambiente virtuale
python -m venv venv

# Attiva l'ambiente
# Windows: .\venv\Scripts\activate
# Mac/Linux: source venv/bin/activate

# Installa le librerie (Basta Flask e CORS, SQLite è già incluso in Python)
pip install flask flask-cors
```

2. Configurazione Frontend
```bash
cd ../frontend
# Installa le dipendenze di React e Tailwind
npm install
```

***Nota***: ⚠️ Il database fitplanner.db viene creato automaticamente al primo avvio del backend.

### 🚀 Come avviare il progetto (Routine Quotidiana)

Ogni volta che vuoi lavorare o usare l'app, devi aprire due terminali separati.

```bash

npm run dev
```

- 👉 Da Telefono: Apri http://192.168.X.X:5173 (L'IP del tuo PC)

2. BACKEND: ENDPOINT E UTILS
----------------------------
**TABELLA ENDPOINT API**
| Metodo | Endpoint Completo | Descrizione |
| :--- | :--- | :--- |
| **AUTH** | | |
| POST | `/api/auth/login` | Login utente (ritorna Token JWT e Ruolo) |
| POST | `/api/auth/reset-password` | Resetta password cliente e invia email simulata |
| **CLIENTS** | | |
| GET | `/api/clients/` | Lista tutti i clienti (solo ruolo 'client') |
| POST | `/api/clients/` | Crea nuovo cliente (genera username/password default) |
| DELETE | `/api/clients/<id>` | Elimina cliente |
| **WORKOUTS** | | |
| GET | `/api/workouts?folder_id=...` | Lista schede (filtrabili per cartella) |
| POST | `/api/workouts` | Crea o Aggiorna una scheda completa (Upsert) |
| DELETE | `/api/workouts/<id>` | Elimina scheda e log associati |
| POST | `/api/workouts/<id>/feedback` | Salva rating e commento cliente |
| **EXERCISES** | | |
| GET | `/api/exercises/<workout_id>` | Lista esercizi di una scheda |
| POST | `/api/exercises/` | Aggiunge esercizio |
| PUT | `/api/exercises/<id>` | Aggiorna esercizio |
| PATCH | `/api/exercises/<id>/notes` | Aggiorna solo le note cliente |
| DELETE | `/api/exercises/<id>` | Elimina esercizio |
| **FOLDERS** | | |
| GET | `/api/folders/<client_id>` | Lista cartelle di un cliente |
| POST | `/api/folders` | Crea cartella |
| DELETE | `/api/folders/<id>` | Elimina cartella |
| **LOGS** | | |
| POST | `/api/logs` | Salva/Aggiorna log (Upsert) per un set specifico |
| GET | `/api/logs/workout/<id>` | Recupera tutti i log di una scheda |

**DECORATORI E UTILS**
- **Decoratori**: Non sono presenti decoratori custom (es. `@requires_auth`) sui singoli endpoint. L'autenticazione è gestita lato Frontend o implicitamente.
- **Utils**:
  - `smtp_service.py`: Contiene `send_recovery_email`. Simula l'invio stampando su terminale.

3. FRONTEND: COMPONENTI E LOGICA
--------------------------------
**MAPPA SUB-COMPONENTI**
- **TrainerDashboard/**
  - `ClientMonitor.jsx`: Gestisce la visualizzazione dei progressi. Contiene logica complessa per "Ghost Data" (ereditare dati dalle settimane precedenti).
  - `WorkoutBuilder/`:
    - `WorkoutCreator.jsx`: Switcha tra `StandardBuilder` e `CircuitBuilder`.
    - `ExerciseItem.jsx`: Gestisce l'UI del singolo esercizio in fase di edit.
- **ClientArea/**
  - `ClientArea.jsx`: Gestisce l'intera vista cliente. Contiene logica per timer, salvataggio log e "Ghost Data".
  - `RecoveryTimer.jsx`: Componente riutilizzabile per il countdown (Modale o Inline).
  - `WorkoutFeedback.jsx`: Form con stelline per il rating finale.

**STATE MANAGEMENT & HOOKS**
- **Stato Globale**: Non viene usato `Context` o `Redux`.
  - L'utente loggato è salvato in `localStorage` ('fit_user', 'fit_token').
  - I dati vengono passati via **Props** (es. `client` passato da `App` a `TrainerDashboard`).
- **Hook Personalizzati**: Non ci sono file hook dedicati (`useFetch.js`), ma la logica di fetch è centralizzata in `src/api/`.
- **Ghost Data Logic**: Implementata localmente in `ClientMonitor` e `ClientArea` (`getLogOrGhost`).

4. DESIGN SYSTEM & TAILWIND CSS
-------------------------------
Il progetto usa un tema "Dark Mode" con accenti Arancioni (`orange-500`) e Smeraldo (`emerald-500` per successi/superset).

**LAYOUT E GRIGLIE (RESPONSIVE)**
- **Breakpoint**: Si usa molto `sm:` (small devices, >640px) e `md:` (medium, >768px).
- **Griglie Comuni**:
  - `grid grid-cols-1 md:grid-cols-2`: 1 colonna su mobile, 2 su desktop.
  - `grid-cols-12`: Usata per allineare i dati degli esercizi (Reps, Kg, Rec) in modo preciso.
- **Container**: `max-w-7xl mx-auto` per centrare il contenuto principale.

**COMPONENTI UI STANDARD**
- **Bottoni Primari**: `bg-orange-500 hover:bg-orange-600 text-white rounded-lg shadow-md transition-all`.
- **Bottoni Secondari**: `bg-slate-800 border border-slate-600 hover:border-orange-500 text-slate-400 hover:text-white`.
- **Card/Pannelli**: `bg-slate-800 border border-slate-700 rounded-xl shadow-lg`.
- **Input**: `bg-slate-900 border border-slate-600 focus:border-orange-500 outline-none rounded-lg`.

**ANIMAZIONI**
- **Transizioni**: `transition-all duration-300` usata su card e bottoni per hover fluidi.
- **Entrate**: `animate-in slide-in-from-top-2 duration-200` usata quando si espande una scheda (Accordion).

5. GUIDA ALLA NAVIGAZIONE RAPIDA
--------------------------------
**MODIFICHE UI COMUNI**
- **Cambiare Colori Dashboard**: `TrainerDashboard.jsx` e `TrainerLayout.jsx`.
- **Modificare Esercizio (Vista Cliente)**: `ClientArea.jsx` (cerca il blocco `return` dentro `w.exercises.map`).

**AGGIUNGERE NUOVI COMPONENTI**

- Se è specifico per il Trainer, mettilo in `src/components/TrainerDashboard/`.

import sqlite3
from config import DB_NAME
import hashlib

def get_db_connection():
    conn = sqlite3.connect(DB_NAME)
    conn.row_factory = sqlite3.Row
    return conn

def hash_password(password):
    # Funzione di hashing che DEVE corrispondere a quella usata per la creazione dell'admin
    return hashlib.sha256(password.encode()).hexdigest()

def init_db():
    conn = get_db_connection()

    # 1. UTENTI
    conn.execute('''
        CREATE TABLE IF NOT EXISTS users (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            name TEXT NOT NULL,
            username TEXT UNIQUE NOT NULL,
            email TEXT,
            password TEXT NOT NULL,
            role TEXT NOT NULL DEFAULT 'client',
            created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
        )
    ''')

    # 2. CARTELLE
    conn.execute('''
        CREATE TABLE IF NOT EXISTS folders (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            name TEXT NOT NULL,
            client_id INTEGER,
            created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
            FOREIGN KEY (client_id) REFERENCES users(id) ON DELETE CASCADE
        )
    ''')

    # 3. SCHEDE (WORKOUTS) - AGGIORNATA PER CIRCUITI
    conn.execute('''
        CREATE TABLE IF NOT EXISTS workouts (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            title TEXT NOT NULL,
            cycle_name TEXT,
            duration_weeks INTEGER DEFAULT 4,
            folder_id INTEGER,
            trainer_id INTEGER,
            client_id INTEGER,
            created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
            rating INTEGER DEFAULT 0,
            client_comment TEXT,
            
            -- NUOVE COLONNE AGGIUNTE
            workout_type TEXT DEFAULT 'standard',
            circuit_rounds INTEGER DEFAULT 0,
            circuit_rest TEXT DEFAULT '',

            FOREIGN KEY (folder_id) REFERENCES folders(id) ON DELETE SET NULL,
            FOREIGN KEY (client_id) REFERENCES users(id) ON DELETE CASCADE
        )
    ''')

    # 4. ESERCIZI
    conn.execute('''
        CREATE TABLE IF NOT EXISTS exercises (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            workout_id INTEGER,
            name TEXT NOT NULL,            
            second_name TEXT,              
            exercise_type TEXT DEFAULT 'normal', 
            sets_reps TEXT,                
            set_types TEXT,                
            recovery TEXT,
            kg_target TEXT,
            trainer_notes TEXT,
            client_notes TEXT,
            exercise_order INTEGER,
            FOREIGN KEY (workout_id) REFERENCES workouts (id) ON DELETE CASCADE
        )
    ''')

    # 5. LOG SETTIMANALI
    conn.execute('''
        CREATE TABLE IF NOT EXISTS weekly_logs (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            exercise_id INTEGER,
            week_number INTEGER,
            set_index INTEGER,
            reps_done TEXT,
            kg_done TEXT,
            notes TEXT,
            updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
            FOREIGN KEY (exercise_id) REFERENCES exercises(id) ON DELETE CASCADE,
            UNIQUE(exercise_id, week_number, set_index)
        )
    ''')

    # Creazione Admin Default se non esiste
    cur = conn.execute("SELECT COUNT(*) as count FROM users WHERE role = 'trainer'")
    count = cur.fetchone()["count"]
    
    if count == 0:
        # HASH CORRETTO GENERATO DAL TUO AMBIENTE LOCALE PER "admin123"
        admin_pass_hash = "240be518fabd2724ddb6f04eeb1da5967448d7e831c08c8fa822809f74c720a9" 
        
        conn.execute(
            "INSERT INTO users (name, username, password, role, email) VALUES (?, ?, ?, ?, ?)", 
            ("Lorenzo Trainer", "lorenzo", admin_pass_hash, "trainer", "tuo_email@example.com")
        )

import jwt
import datetime
import random
import string

from utils.smtp_service import send_recovery_email
from config import SECRET_KEY


# ECCOLA QUI LA DEFINIZIONE CHE MANCAVA:
auth_bp = Blueprint('auth', __name__, url_prefix='/api/auth')

# --- LOGIN ---
@auth_bp.route('/login', methods=['POST'])
def login():
    data = request.json
    username = data.get('username')
    password = data.get('password')

    if not username or not password:
        return jsonify({'error': 'Dati mancanti'}), 400

    hashed_pw = hash_password(password)

    conn = get_db_connection()
    user = conn.execute(
        'SELECT * FROM users WHERE username = ? AND password = ?', 
        (username, hashed_pw)
    ).fetchone()
    conn.close()

    if user:
        token_payload = {
            'user_id': user['id'],
            'username': user['username'],
            'role': user['role'],
            'name': user['name'],
            'exp': datetime.datetime.utcnow() + datetime.timedelta(hours=24)
        }
        
        token = jwt.encode(token_payload, SECRET_KEY, algorithm="HS256")
        
        return jsonify({
            'token': token,
            'role': user['role'],
            'name': user['name'],
            'id': user['id']
        })

    return jsonify({'error': 'Credenziali errate'}), 401

# --- RESET PASSWORD ---
@auth_bp.route('/reset-password', methods=['POST'])
def reset_password():
    data = request.json
    client_id = data.get('client_id')
    
    new_password = ''.join(random.choices(string.ascii_letters + string.digits, k=6))
    hashed_new = hash_password(new_password)

    conn = get_db_connection()
    user = conn.execute('SELECT email, username FROM users WHERE id = ?', (client_id,)).fetchone()
    
    if not user:
        conn.close()
        return jsonify({"error": "Utente non trovato"}), 404

    conn.execute('UPDATE users SET password = ? WHERE id = ?', (hashed_new, client_id))
    conn.commit()
    conn.close()

    if user['email']:
        send_recovery_email(user['email'], new_password)

    return jsonify({
        "message": "Password resettata con successo!", 
        "new_password": new_password, 
        "username": user['username']
    })

# Questo file gestirà il salvataggio e il recupero dei dati specifici per ogni settimana (Kg e Reps effettivi inseriti dal cliente)

from flask import Blueprint, request, jsonify
from db import get_db_connection

logs_bp = Blueprint('logs', __name__, url_prefix='/api/logs')

# --- SALVA LOG (Upsert) ---
# Salva o aggiorna un dato per una specifica serie di una specifica settimana
@logs_bp.route('', methods=['POST'])
def save_log():
    data = request.json
    exercise_id = data.get('exercise_id')
    week_number = data.get('week_number')
    set_index = data.get('set_index')
    
    reps = data.get('reps', '')
    kg = data.get('kg', '')
    notes = data.get('notes', '')

    if not exercise_id or not week_number:
        return jsonify({"error": "Dati incompleti"}), 400

    conn = get_db_connection()
    cur = conn.cursor()

    # Controlla se esiste già un log per questa combinazione (Esercizio + Settimana + Serie)
    existing = cur.execute(
        "SELECT id FROM weekly_logs WHERE exercise_id=? AND week_number=? AND set_index=?",
        (exercise_id, week_number, set_index)
    ).fetchone()

    if existing:
        # Se esiste, AGGIORNA
        cur.execute(
            "UPDATE weekly_logs SET reps_done=?, kg_done=?, notes=?, updated_at=CURRENT_TIMESTAMP WHERE id=?",
            (reps, kg, notes, existing['id'])
        )
    else:
        # Se non esiste, CREA NUOVO
        cur.execute(
            "INSERT INTO weekly_logs (exercise_id, week_number, set_index, reps_done, kg_done, notes) VALUES (?, ?, ?, ?, ?, ?)",
            (exercise_id, week_number, set_index, reps, kg, notes)
        )

    conn.commit()
    conn.close()
    return jsonify({"message": "Log salvato"}), 200

# --- LEGGI LOG DI UNA SCHEDA ---
# Serve al Frontend per mostrare lo storico quando apri la scheda
@logs_bp.route('/workout/<int:workout_id>', methods=['GET'])
def get_workout_logs(workout_id):
    conn = get_db_connection()
    
    # Recupera tutti i log collegati agli esercizi di questa scheda
    # Facciamo una JOIN per essere sicuri di prendere solo i log di QUESTO workout
    logs = conn.execute('''
        SELECT l.exercise_id, l.week_number, l.set_index, l.reps_done, l.kg_done, l.notes
        FROM weekly_logs l
        JOIN exercises e ON l.exercise_id = e.id
        WHERE e.workout_id = ?
    ''', (workout_id,)).fetchall()
    
    conn.close()
    # Restituiamo una lista semplice di oggetti
    return jsonify([dict(l) for l in logs])

from flask import Blueprint, request, jsonify
from db import get_db_connection

workouts_bp = Blueprint('workouts', __name__)

@workouts_bp.route('/api/workouts', methods=['GET'])
def get_workouts():
    folder_id = request.args.get('folder_id')
    conn = get_db_connection()
    
    # Recuperiamo anche i campi nuovi (circuiti)
    if folder_id:
        workouts = conn.execute('SELECT * FROM workouts WHERE folder_id = ? ORDER BY created_at DESC', (folder_id,)).fetchall()
    else:
        workouts = conn.execute('SELECT * FROM workouts ORDER BY created_at DESC').fetchall()
    
    result = []
    for w in workouts:
        w_dict = dict(w)
        # Default 'standard' se il campo è null (sicurezza per vecchi record)
        if 'workout_type' not in w_dict or w_dict['workout_type'] is None:
            w_dict['workout_type'] = 'standard'
        
        # Recupera esercizi ordinati
        try:
            exercises = conn.execute('SELECT * FROM exercises WHERE workout_id = ? ORDER BY exercise_order', (w['id'],)).fetchall()
        except:
            # Fallback se la colonna exercise_order non esiste ancora
            exercises = conn.execute('SELECT * FROM exercises WHERE workout_id = ? ORDER BY id', (w['id'],)).fetchall()
            
        w_dict['exercises'] = [dict(e) for e in exercises]
        result.append(w_dict)
    
    conn.close()
    return jsonify(result)

@workouts_bp.route('/api/workouts', methods=['POST'])
def create_workout():
    data = request.json
    conn = get_db_connection()
    
    # Leggiamo i dati del circuito e LA DURATA IN SETTIMANE (AGGIUNTO)
    w_type = data.get('workout_type', 'standard')
    c_rounds = data.get('circuit_rounds', 0)
    c_rest = data.get('circuit_rest', '')
    folder_id = data.get('folder_id')
    # AGGIUNTO: Leggiamo la durata in settimane
    duration = data.get('duration_weeks', 4) 

    try:
        if 'id' in data:
            # --- UPDATE ---
            # AGGIUNTO: 'duration_weeks = ?' nella query UPDATE
            conn.execute('''
                UPDATE workouts 
                SET title = ?, folder_id = ?, workout_type = ?, circuit_rounds = ?, circuit_rest = ?, duration_weeks = ?
                WHERE id = ?
            ''', (data['title'], folder_id, w_type, c_rounds, c_rest, duration, data['id']))
            workout_id = data['id']
            # Rimuoviamo i vecchi esercizi per risalvarli
            conn.execute('DELETE FROM exercises WHERE workout_id = ?', (workout_id,))
        else:
            # --- CREATE ---
            # AGGIUNTO: 'duration_weeks' sia nell'elenco delle colonne che nell'elenco dei VALUES
            cur = conn.execute('''
                INSERT INTO workouts (trainer_id, client_id, folder_id, title, created_at, workout_type, circuit_rounds, circuit_rest, duration_weeks)
                VALUES (?, ?, ?, ?, CURRENT_TIMESTAMP, ?, ?, ?, ?)
            ''', (data['trainer_id'], data['client_id'], folder_id, data['title'], w_type, c_rounds, c_rest, duration))
            workout_id = cur.lastrowid

        # --- INSERT ESERCIZI ---
        for i, ex in enumerate(data['exercises']):
            
            # CRITICO: ESTRAIAMO IL CAMPO 'mode' CHE ORA E' SALVATO IN set_types
            current_set_types = ex.get('set_types', 'normal')

            conn.execute('''
                INSERT INTO exercises (
                    workout_id, name, second_name, exercise_type, 
                    sets_reps, kg_target, recovery, trainer_notes, client_notes, 
                    set_types, exercise_order
                )
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
            ''', (
                workout_id, 
                ex['name'], 
                ex.get('second_name'), 
                # Per i circuiti flessibili, il tipo è sempre 'circuit' qui
                ex.get('exercise_type', 'circuit'), 
                ex['sets_reps'],      # Contiene REPS O WORK TIME
                ex['kg_target'],      # Contiene KG
                ex['recovery'],       # Contiene RECUPERO INTER-SET O REST TIME
                ex.get('trainer_notes', ''), 
                ex.get('client_notes', ''), 
                current_set_types,    # CONTIENE 'reps' o 'timer'
                i # exercise_order
            ))
        
        conn.commit()
        return jsonify({'id': workout_id, 'message': 'Workout saved'})
    except Exception as e:
        conn.rollback()
        print(f"ERROR WORKOUT SAVE: {e}") # Debug nel terminale
        return jsonify({'error': str(e)}), 500
    finally:
        conn.close()

@workouts_bp.route('/api/workouts/<int:id>', methods=['DELETE'])
def delete_workout(id):
    conn = get_db_connection()
    try:
        # Trova ID esercizi per cancellare i log corretti
        exercises = conn.execute('SELECT id FROM exercises WHERE workout_id = ?', (id,)).fetchall()
        exercise_ids = [e['id'] for e in exercises]
        
        if exercise_ids:
            # Cancella i log associati agli esercizi (Tabella: weekly_logs)
            placeholders = ','.join('?' * len(exercise_ids))
            conn.execute(f'DELETE FROM weekly_logs WHERE exercise_id IN ({placeholders})', exercise_ids)
            # Cancella gli esercizi
            conn.execute('DELETE FROM exercises WHERE workout_id = ?', (id,))
            
        # Cancella il workout
        conn.execute('DELETE FROM workouts WHERE id = ?', (id,))
        
        conn.commit()
        return jsonify({'message': 'Deleted'})
    except Exception as e:
        conn.rollback()
        print(f"DELETE ERROR: {e}")
        return jsonify({'error': str(e)}), 500
    finally:
        conn.close()

export async function loginUser(username, password) {
  try {
    // Usiamo API_URL (che ora sarà HTTPS) invece di un indirizzo scritto a mano
    const res = await fetch(`${API_URL}/auth/login`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ username, password })
    });

    const data = await res.json();
    
    // Controlliamo sempre che la risposta HTTP sia OK
    if (!res.ok) {
      // Se fallisce, lanciamo l'errore che viene catturato da LoginForm
      throw new Error(data.error || 'Errore di login');
    }

    // Se va tutto bene, restituiamo il pacchetto con il token
    return data; 
  } catch (err) {
    console.error("Login Error:", err);
    throw err;
  }
}

            setWorkouts(data);

            data.forEach(w => {
                fetchWorkoutLogs(w.id).then(workoutLogs => {
                    setLogs(prev => ({ ...prev, [w.id]: workoutLogs }));
                });
                setActiveWeeks(prev => ({ ...prev, [w.id]: 1 }));
            });

            // Espande la prima scheda e il primo esercizio per default
            if (data.length > 0) {
                setExpandedWorkouts([data[0].id]);
                if (data[0].exercises && data[0].exercises.length > 0) {
                    setExpandedExercises(new Set([data[0].exercises[0].id]));
                }
            }
        } catch (error) {
            console.error("Errore caricamento schede:", error);
        }
    };

    // --- LOGICA LOG ---
    const getLogEntry = (workoutId, exerciseId, week, setIdx) => {
        const wLogs = logs[workoutId] || [];
        return wLogs.find(l => l.exercise_id === exerciseId && l.week_number === week && l.set_index === setIdx) || {};
    };

    const getLogOrGhost = (workoutId, exerciseId, week, setIdx, field) => {
        for (let w = week; w >= 1; w--) {
            const entry = getLogEntry(workoutId, exerciseId, w, setIdx);
            const val = field === 'reps' ? entry.reps_done : entry.kg_done;

            if (val !== undefined && val !== null && val !== "") {
                return val;
            }
        }
        return "";
    };

    const saveLogData = async (workoutId, exerciseId, setIdx, week, newEntry, currentLog) => {
        await saveLog({
            exercise_id: exerciseId,
            week_number: week,
            set_index: setIdx,
            reps: newEntry.reps_done || (currentLog.reps_done || ''),
            kg: newEntry.kg_done || (currentLog.kg_done || ''),
            notes: newEntry.notes || (currentLog.notes || '')
        });
    };

    const handleLogChange = async (workoutId, exerciseId, setIdx, field, value) => {
        const week = activeWeeks[workoutId] || 1;
        setLogs(prev => {
            const wLogs = prev[workoutId] ? [...prev[workoutId]] : [];
            const existingIdx = wLogs.findIndex(l => l.exercise_id === exerciseId && l.week_number === week && l.set_index === setIdx);
            const current = wLogs[existingIdx] || {};
            const newEntry = {
                exercise_id: exerciseId, week_number: week, set_index: setIdx,
                reps_done: field === 'reps' ? value : (current.reps_done || ''),
                kg_done: field === 'kg' ? value : (current.kg_done || ''),
                notes: field === 'notes' ? value : (current.notes || '')
            };
            if (existingIdx >= 0) wLogs[existingIdx] = newEntry;
            else wLogs.push(newEntry);
            return { ...prev, [workoutId]: wLogs };
        });
        const currentLog = getLogEntry(workoutId, exerciseId, week, setIdx);
        const updateObj = {};
        if (field === 'reps') updateObj.reps_done = value;
        if (field === 'kg') updateObj.kg_done = value;
        if (field === 'notes') updateObj.notes = value;
        await saveLogData(workoutId, exerciseId, setIdx, week, updateObj, currentLog);
    };

    const handleSplitLogChange = async (workoutId, exerciseId, setIdx, field, subIndex, value) => {
        const week = activeWeeks[workoutId] || 1;
        const currentLog = getLogEntry(workoutId, exerciseId, week, setIdx);
        const currentVal = (field === 'reps' ? currentLog.reps_done : currentLog.kg_done) || "";
        let parts = currentVal.toString().split("+");
        if (parts.length < 2) parts = [currentVal, ""];
        parts[subIndex] = value;
        const finalVal = parts.join("+");
        handleLogChange(workoutId, exerciseId, setIdx, field, finalVal);
    };

    const getSplitLogVal = (workoutId, exerciseId, week, setIdx, field, subIndex) => {
        for (let w = week; w >= 1; w--) {
            const entry = getLogEntry(workoutId, exerciseId, w, setIdx);
            const val = (field === 'reps' ? entry.reps_done : entry.kg_done) || "";
            if (val !== "") {
                const parts = val.toString().split("+");
                return parts[subIndex] || "";
            }
        }
        return "";
    };

    const handleTimerFinish = (workoutId, exerciseId, setIndex) => {
        const setKey = `${workoutId}-${exerciseId}-${setIndex}`;
        setCompletedSets(prev => new Set(prev).add(setKey));
    };

    const handleManualComplete = (workoutId, exerciseId, setIndex) => {
        const setKey = `${workoutId}-${exerciseId}-${setIndex}`;
        setCompletedSets(prev => {
            const newSet = new Set(prev);
            if (newSet.has(setKey)) {
                newSet.delete(setKey); // Rimuove se già completato
            } else {
                newSet.add(setKey);    // Aggiunge se non completato
            }
            return newSet;
        });
    };

    const toggleWorkout = (id) => {
        setExpandedWorkouts(prev => prev.includes(id) ? prev.filter(wid => wid !== id) : [...prev, id]);
    };

    const toggleExercise = (id) => {
        setExpandedExercises(prev => {
            const newSet = new Set(prev);
            if (newSet.has(id)) {
                newSet.delete(id);
            } else {
                newSet.add(id);
            }
            return newSet;
        });
    };

    // Helper per dividere i valori
    const splitData = (str) => (str ? str.toString().split(" / ") : []);

    const getRoundValue = (str, roundIndex) => {
        const parts = splitData(str);
        if (parts.length > roundIndex) return parts[roundIndex];
        return parts[0] || "-";
    };

    const getSplitTarget = (val, index) => {
        if (!val) return "-";
        const parts = val.toString().split("+");
        return parts[index] || "-";
    };

    const parseSets = (ex) => {
        const reps = splitData(ex.sets_reps);
        const kgs = splitData(ex.kg_target);
        const rests = splitData(ex.recovery);
        const trainerNotes = splitData(ex.trainer_notes);
        const types = splitData(ex.set_types);

        return reps.map((r, i) => ({
            reps: r,
            kg: kgs[i] || "-",
            rest: rests[i] || "-",
            t_note: trainerNotes[i] || "-",
            type: types[i] || "normal"
        }));
    };

    // --- COMPONENTE INTERNO: INPUT O TIMER ---
    const InputOrTimer = ({ placeholder, isSplitted = false, splitIndex = 0, workoutId, exerciseId, realIndex }) => {
        const [mode, setMode] = useState('input');

        const currentWeek = activeWeeks[workoutId];
        const displayValue = isSplitted
            ? getSplitLogVal(workoutId, exerciseId, currentWeek, realIndex, 'reps', splitIndex)
            : getLogOrGhost(workoutId, exerciseId, currentWeek, realIndex, 'reps');

        const handleValueChange = (e) => {
            if (isSplitted) {
                handleSplitLogChange(workoutId, exerciseId, realIndex, 'reps', splitIndex, e.target.value);
            } else {
                handleLogChange(workoutId, exerciseId, realIndex, 'reps', e.target.value);
            }
        };

        const onFinishTimer = () => handleManualComplete(workoutId, exerciseId, realIndex);

        if (mode === 'timer') {
            const timerValue = placeholder.includes('"') || placeholder.includes("'") ? placeholder : `${placeholder}"`;
            return (
                <div className="relative w-full h-full min-h-[34px] flex items-center justify-center bg-slate-800 rounded border border-blue-500/50">
                    <RecoveryTimer
                        value={timerValue}
                        onFinish={onFinishTimer}
                        small={true}
                        accentColor="emerald"
                    />
                    <button
                        onClick={() => setMode('input')}
                        className="absolute -top-2 -right-2 bg-slate-700 text-slate-300 rounded-full p-0.5 border border-slate-500 hover:bg-slate-600"
                        title="Torna a testuale"
                    >
                        <div className="w-2.5 h-2.5 flex items-center justify-center font-bold text-[8px]">T</div>
                    </button>
                </div>
            );
        }

        return (
            <div className="relative w-full">
                <input
                    type="text"
                    className="w-full text-center bg-transparent text-white font-bold border-b border-slate-600 focus:border-orange-500 outline-none p-1 text-sm"
                    placeholder={placeholder}
                    value={displayValue}
                    onChange={handleValueChange}
                />
                <button
                    onClick={() => setMode('timer')}
                    className="absolute right-0 top-1 text-slate-600 hover:text-blue-400 transition-colors"
                    title="Usa Timer (es. Plank)"
                >
                    <Timer size={12} />
                </button>
            </div>
        );
    };

    return (
        <div className="p-4 space-y-6 bg-slate-800 rounded-xl shadow-lg border border-slate-700 max-w-2xl mx-auto pb-20">

            {/* HEADER */}
            <div className="flex flex-col sm:flex-row justify-between items-start sm:items-center gap-4 border-b border-slate-700 pb-4">
                <div>
                    <h3 className="font-bold text-2xl text-white flex items-center gap-2"><ClipboardList className="text-orange-500" /> Le tue Schede</h3>
                    <p className="text-sm text-slate-400">Seleziona una cartella per vedere il programma</p>
                </div>
                <select
                    className="bg-slate-900 border border-slate-600 text-white p-2.5 rounded-lg text-sm font-bold outline-none focus:ring-1 focus:ring-orange-500 w-full sm:w-auto"
                    value={selectedFolder || ""} onChange={e => setSelectedFolder(parseInt(e.target.value))} disabled={folders.length === 0}
                >
                    {folders.length === 0 && <option>Nessuna cartella</option>}
                    {folders.map(f => (
                        <option key={f.id} value={f.id} className="bg-slate-800">{f.name}</option>
                    ))}
                </select>
            </div>

            {workouts.length === 0 && folders.length > 0 && (
                <div className="text-center py-10 bg-slate-900 rounded-lg border border-dashed border-slate-700">
                    <p className="text-slate-500 italic">Nessuna scheda presente.</p>
                </div>
            )}

            {workouts.map(w => {
                const isOpen = expandedWorkouts.includes(w.id);
                const currentWeek = activeWeeks[w.id] || 1;
                const isCircuit = w.workout_type === 'circuit';

                return (
                    <div key={w.id} className="bg-slate-800 border border-slate-700 rounded-2xl overflow-hidden shadow-md mb-4 transition-all">

                        {/* HEADER SCHEDA */}
                        <div onClick={() => toggleWorkout(w.id)} className="bg-slate-900 text-white p-4 flex justify-between items-center border-b border-slate-700 cursor-pointer hover:bg-slate-800 transition-colors">
                            <div>
                                <h4 className="font-bold text-lg flex items-center gap-2">
                                    {w.title}
                                </h4>
                            </div>
                            <div className="text-slate-400">{isOpen ? <ChevronUp size={20} /> : <ChevronDown size={20} />}</div>
                        </div>

                        {isOpen && (
                            <div className="animate-in slide-in-from-top-2 duration-200">

                                {/* TABS SETTIMANE */}
                                <div className="flex gap-2 overflow-x-auto p-3 bg-slate-900/50 border-b border-slate-700 scrollbar-hide">
                                    {[...Array(parseInt(w.duration_weeks) || 1)].map((_, i) => {
                                        const weekNum = i + 1;
                                        return (
                                            <button key={weekNum} onClick={() => setActiveWeeks(prev => ({ ...prev, [w.id]: weekNum }))}
                                                className={`px-3 py-1.5 rounded-lg text-xs font-bold whitespace-nowrap transition-all border ${currentWeek === weekNum ? "bg-orange-600 text-white border-orange-500" : "bg-slate-800 text-slate-400 border-slate-600"}`}>
                                                Sett {weekNum}
                                            </button>
                                        )
                                    })}
                                </div>

                                {/* --- LOGICA DI VISUALIZZAZIONE --- */}

                                {/* A. VISUALIZZAZIONE CIRCUITO */}
                                {isCircuit ? (
                                    <div className="p-3 space-y-6">
                                        {[...Array(w.circuit_rounds || 1)].map((_, roundIndex) => (
                                            <div key={roundIndex} className="border-2 border-orange-500/20 rounded-xl overflow-hidden bg-slate-900/30">

                                                {/* Header del Giro */}
                                                <div className="bg-orange-900/20 p-3 border-b border-orange-500/20 flex justify-between items-center">
                                                    <h5 className="text-orange-400 font-bold uppercase tracking-wider flex items-center gap-2">
                                                        <Repeat size={16} /> Giro {roundIndex + 1}
                                                    </h5>
                                                    <span className="text-xs text-orange-500/60 font-mono">{roundIndex + 1} di {w.circuit_rounds}</span>
                                                </div>

                                                {/* Lista Esercizi del Giro */}
                                                <div className="divide-y divide-slate-700/50">
                                                    {w.exercises.map((ex) => {
                                                        const mode = getRoundValue(ex.set_types, roundIndex);
                                                        const isTimerMode = mode === 'timer';

                                                        const targetWork = getRoundValue(ex.sets_reps, roundIndex);
                                                        const targetRest = getRoundValue(ex.recovery, roundIndex);
                                                        const targetKg = getRoundValue(ex.kg_target, roundIndex);
                                                        const targetNote = getRoundValue(ex.trainer_notes, roundIndex);

                                                        const currentLog = getLogEntry(w.id, ex.id, currentWeek, roundIndex);
                                                        const setKey = `${w.id}-${ex.id}-${roundIndex}`;
                                                        const isCompleted = completedSets.has(setKey);

                                                        const displayWork = getLogOrGhost(w.id, ex.id, currentWeek, roundIndex, 'reps');
                                                        const displayKg = getLogOrGhost(w.id, ex.id, currentWeek, roundIndex, 'kg');

                                                        const workLabel = isTimerMode ? 'Tempo (sec)' : 'Reps';
                                                        const targetReps = targetWork;

                                                        return (
                                                            <div key={ex.id} className={`p-3 ${isCompleted ? 'bg-emerald-900/10' : ''}`}>
                                                                <div className="mb-2 flex items-center justify-between">
                                                                    <div className="flex items-center gap-3">
                                                                        {/* Bottone Completamento Manuale */}
                                                                        <button onClick={() => handleManualComplete(w.id, ex.id, roundIndex)}
                                                                            className={`text-xs font-bold w-6 h-6 flex items-center justify-center rounded-full border transition-colors flex-shrink-0 ${isCompleted ? 'bg-emerald-500 text-white border-emerald-400' : 'bg-slate-800 text-slate-400 border-slate-600 hover:bg-emerald-800/50'}`}>
                                                                            {roundIndex + 1}
                                                                        </button>
                                                                        <span className="font-bold text-white text-sm">{ex.name}</span>
                                                                    </div>
                                                                    {targetNote && targetNote !== '-' && (
                                                                        <div className="flex items-center gap-1 text-xs text-orange-400 bg-orange-900/20 px-2 py-0.5 rounded border border-orange-900/30">
                                                                            <Info size={12} />
                                                                            <span>{targetNote}</span>
                                                                        </div>
                                                                    )}
                                                                </div>

                                                                <div className="grid grid-cols-12 gap-2 items-center">
                                                                    <div className="col-span-3 text-center relative">
                                                                        <span className="text-[8px] text-slate-500 uppercase block mb-0.5">{workLabel}</span>
                                                                        {isTimerMode ? (
                                                                            <RecoveryTimer value={targetWork} onFinish={() => handleManualComplete(w.id, ex.id, roundIndex)} small={true} accentColor="emerald" />
                                                                        ) : (
                                                                            <input type="text" className={`w-full bg-slate-800 text-white text-center border border-slate-600 rounded p-1.5 text-sm font-bold focus:border-orange-500 outline-none`}
                                                                                placeholder={targetWork}
                                                                                value={displayWork}
                                                                                onChange={(e) => handleLogChange(w.id, ex.id, roundIndex, 'reps', e.target.value)}
                                                                            />
                                                                        )}
                                                                    </div>
                                                                    <div className="col-span-3 text-center relative">
                                                                        <span className="text-[8px] text-slate-500 uppercase block mb-0.5">Kg</span>
                                                                        <input type="text" className={`w-full bg-slate-800 text-white text-center border border-slate-600 rounded p-1.5 text-sm font-bold focus:border-orange-500 outline-none`}
                                                                            placeholder={targetKg}
                                                                            value={displayKg}
                                                                            onChange={(e) => handleLogChange(w.id, ex.id, roundIndex, 'kg', e.target.value)}
                                                                        />
                                                                    </div>
                                                                    <div className="col-span-3 flex flex-col items-center">
                                                                        <span className="text-[8px] text-slate-500 uppercase block mb-0.5">{isTimerMode ? 'Riposo' : 'Rec'}</span>
                                                                        {isTimerMode ? (
                                                                            <RecoveryTimer value={targetRest} onFinish={() => { }} small={true} accentColor="red" />
                                                                        ) : (
                                                                            <RecoveryTimer value={targetRest} onFinish={() => handleTimerFinish(w.id, ex.id, roundIndex)} small={true} accentColor="orange" />
                                                                        )}
                                                                    </div>
                                                                    <div className="col-span-3">
                                                                        <span className="text-[8px] text-slate-500 uppercase block mb-0.5">Note</span>
                                                                        <input type="text" className={`w-full bg-slate-800 text-slate-300 text-xs border border-slate-600 rounded p-2 focus:border-orange-500 outline-none`}
                                                                            placeholder="..."
                                                                            value={currentLog.notes || ""}
                                                                            onChange={(e) => handleLogChange(w.id, ex.id, roundIndex, 'notes', e.target.value)}
                                                                        />
                                                                    </div>
                                                                </div>
                                                            </div>
                                                        );
                                                    })}
                                                </div>
                                                <div className="bg-slate-900 p-4 flex flex-col items-center justify-center border-t border-slate-700 gap-2">
                                                    <span className="text-xs uppercase font-bold text-slate-400 tracking-widest">Recupero Fine Giro</span>
                                                    <RecoveryTimer value={w.circuit_rest} />
                                                </div>
                                            </div>
                                        ))}
                                    </div>
                                ) : (
                                    // B. VISUALIZZAZIONE STANDARD
                                    <div className="divide-y divide-slate-700">
                                        {w.exercises.map(ex => {
                                            const sets = parseSets(ex);
                                            const isSuperSet = ex.exercise_type === 'superset';
                                            const isOpenExercise = expandedExercises.has(ex.id);

                                            return (
                                                <div key={ex.id} className={`transition-all duration-300 ${isOpenExercise ? 'bg-slate-800' : 'hover:bg-slate-700/30'} rounded-xl overflow-hidden border border-slate-700`}>

                                                    {/* HEADER ESERCIZIO (Cliccabile) */}
                                                    <div onClick={() => toggleExercise(ex.id)}
                                                         className="p-4 flex justify-between items-center cursor-pointer hover:bg-slate-700/50 transition-colors">

                                                        <div className="flex items-center">
                                                            <h5 className="font-bold text-slate-200 text-lg flex items-center flex-wrap gap-2">
                                                                {isSuperSet ? <Link size={18} className="text-emerald-500" /> : <ChevronRight size={18} className="text-orange-500" />}
                                                                <span>{ex.name}</span>
                                                                {isSuperSet && ex.second_name && (
                                                                    <span className="text-white"> + {ex.second_name}</span>
                                                                )}
                                                            </h5>
                                                        </div>

                                                        <div className="text-slate-400">
                                                            {isOpenExercise ? <ChevronUp size={20} /> : <ChevronDown size={20} />}
                                                        </div>
                                                    </div>

                                                    {isOpenExercise && (
                                                        <div className="p-4 pt-0 space-y-3 animate-in slide-in-from-top-2 duration-200">

                                                            {sets.map((set, i) => {
                                                                const setKey = `${w.id}-${ex.id}-${i}`;
                                                                const isCompleted = completedSets.has(setKey);
                                                                const currentLog = getLogEntry(w.id, ex.id, currentWeek, i);
                                                                const isStripping = set.type === 'stripping';
                                                                const isRestPause = set.type === 'rest_pause';

                                                                if (isRestPause || isStripping) {
                                                                    const typeLabel = isRestPause ? 'Rest Pause' : 'Stripping';
                                                                    const typeColor = isRestPause ? 'blue' : 'red';

                                                                    const targetReps1 = getSplitTarget(set.reps, 0);
                                                                    const targetReps2 = getSplitTarget(set.reps, 1);
                                                                    
                                                                    const targetKg1 = isStripping ? getSplitTarget(set.kg, 0) : set.kg;
                                                                    const targetKg2 = isStripping ? getSplitTarget(set.kg, 1) : set.kg;
                                                                    
                                                                    const set_1 = { 
                                                                        reps: targetReps1, 
                                                                        kg: targetKg1, 
                                                                        rest: getSplitTarget(set.rest, 0) 
                                                                    };
                                                                    const set_2 = { 
                                                                        reps: getSplitTarget(set.reps, 1), 
                                                                        kg: targetKg2, 
                                                                        rest: getSplitTarget(set.rest, 1) 
                                                                    };

                                                                    const displayReps1 = getSplitLogVal(w.id, ex.id, currentWeek, i, 'reps', 0);
                                                                    const displayKg1 = getSplitLogVal(w.id, ex.id, currentWeek, i, 'kg', 0);
                                                                    const displayReps2 = getSplitLogVal(w.id, ex.id, currentWeek, i, 'reps', 1);
                                                                    const displayKg2 = isStripping
                                                                        ? getSplitLogVal(w.id, ex.id, currentWeek, i, 'kg', 1)
                                                                        : displayKg1;

                                                                    const renderSplitRow = (subIndex, target, displayReps, displayKg) => {
                                                                        const isSecondRound = subIndex === 1;
                                                                        // MODIFICATO QUI: Logica corretta per RestPause e Stripping
                                                                        const finalRest = isRestPause 
                                                                            ? getSplitTarget(set.rest, subIndex) // Rest Pause: prende 3 o 5
                                                                            : (isStripping && subIndex === 1 ? set.rest : "0"); // Stripping: solo Drop 2 ha Rec
                                                                        
                                                                        const shouldHideTimer = isStripping && subIndex === 0;

                                                                        return (
                                                                            <div key={`split-${subIndex}`} className={`grid grid-cols-12 gap-2 items-center ${isSecondRound ? 'pt-2 border-t border-slate-700/50' : 'pb-1'}`}>
                                                                                <div className="col-span-12 sm:col-span-2 flex items-center text-xs font-medium text-slate-400">
                                                                                    <span className={`text-${typeColor}-400 font-bold mr-1`}>{subIndex + 1}:</span> Giro {subIndex + 1}
                                                                                </div>
                                                                                <div className="col-span-4 sm:col-span-3 text-center flex items-center gap-1 justify-center">
                                                                                    <input type="text" className={`w-1/2 text-center bg-slate-800 text-white font-bold border border-slate-700 rounded-lg focus:border-${typeColor}-500 outline-none p-2 text-sm`}
                                                                                        placeholder={target.reps}
                                                                                        value={displayReps}
                                                                                        onChange={(e) => handleSplitLogChange(w.id, ex.id, i, 'reps', subIndex, e.target.value)}
                                                                                    />
                                                                                    <span className="text-slate-500 text-xs">reps</span>
                                                                                </div>
                                                                                <div className="col-span-4 sm:col-span-3 text-center flex items-center gap-1 justify-center">
                                                                                    <input type="text"
                                                                                        className={`w-1/2 text-center bg-slate-800 text-white font-bold border border-slate-700 rounded-lg focus:border-${typeColor}-500 outline-none p-2 text-sm`}
                                                                                        placeholder={target.kg}
                                                                                        value={displayKg}
                                                                                        onChange={(e) => isStripping
                                                                                            ? handleSplitLogChange(w.id, ex.id, i, 'kg', subIndex, e.target.value)
                                                                                            : handleLogChange(w.id, ex.id, i, 'kg', e.target.value)
                                                                                        }
                                                                                        disabled={isRestPause && isSecondRound}
                                                                                    />
                                                                                    <span className="text-slate-500 text-xs">kg</span>
                                                                                </div>
                                                                                <div className="col-span-4 sm:col-span-4 flex items-center gap-2 justify-center sm:justify-start">
                                                                                    <Timer size={16} className="text-slate-500" />
                                                                                    {shouldHideTimer ? (
                                                                                        <div className="w-16 h-8 bg-slate-800 rounded-lg border border-slate-700 flex items-center justify-center text-xs text-slate-400 font-bold">
                                                                                            -
                                                                                        </div>
                                                                                    ) : (
                                                                                        <RecoveryTimer value={finalRest} onFinish={isSecondRound ? () => handleTimerFinish(w.id, ex.id, i) : null} />
                                                                                    )}
                                                                                </div>
                                                                            </div>
                                                                        );
                                                                    }

                                                                    return (
                                                                        <div key={i} className={`p-3 rounded-xl shadow-md border transition-all duration-300 space-y-2 ${isCompleted ? 'bg-emerald-900/10 border-emerald-500/30' : `bg-slate-900 border-${typeColor}-700/50`}`}>

import React, { useState, useEffect } from 'react';
import { Play, Pause, Square, Timer, RotateCcw } from 'lucide-react';

// AGGIUNTO accentColor TRA I PROPS
export default function RecoveryTimer({ value, onFinish, small, accentColor = 'orange' }) {
  const [status, setStatus] = useState('idle');
  const [timeLeft, setTimeLeft] = useState(0);
  const [originalTime, setOriginalTime] = useState(0);

  // --- FUNZIONE PER GENERARE IL BIP SONORO ---
  const playBeep = () => {
    try {
      const AudioContext = window.AudioContext || window.webkitAudioContext;
      if (!AudioContext) return; 

      const audioCtx = new AudioContext();
      const oscillator = audioCtx.createOscillator();
      const gainNode = audioCtx.createGain();

      oscillator.connect(gainNode);
      gainNode.connect(audioCtx.destination);

      oscillator.type = "sine"; 
      oscillator.frequency.setValueAtTime(880, audioCtx.currentTime); 
      gainNode.gain.setValueAtTime(0.1, audioCtx.currentTime); 

      oscillator.start();
      oscillator.stop(audioCtx.currentTime + 0.5); 
    } catch (e) {
      console.error("Errore audio:", e);
    }
  };

  useEffect(() => {
    if (!value) return;
    const numericValue = parseInt(value.toString().replace(/\D/g, '')); // Gestisce anche i valori tipo "90'"

    if (!isNaN(numericValue) && numericValue > 0) {
      setOriginalTime(numericValue);
      setTimeLeft(numericValue);
    }
  }, [value]);

  useEffect(() => {
    let interval = null;

    if (status === 'running' && timeLeft > 0) {
      interval = setInterval(() => {
        setTimeLeft((prev) => prev - 1);
      }, 1000);
    } else if (timeLeft === 0 && status === 'running') {
      // --- TEMPO SCADUTO! ---
      setStatus('finished');
      playBeep();
      // NOTIFICA AL PADRE CHE IL TEMPO È SCADUTO
      if (onFinish) {
        onFinish();
      }
      clearInterval(interval);
    }

    return () => clearInterval(interval);
  }, [status, timeLeft, onFinish]);

  const handleStart = () => setStatus('running');
  const handlePause = () => setStatus('paused');
  
  const handleStop = () => {
    setStatus('idle');
    setTimeLeft(originalTime);
  };

  const formatTime = (seconds) => {
    const m = Math.floor(seconds / 60);
    const s = seconds % 60;
    return `${m}:${s < 10 ? '0' : ''}${s}`;
  };
  
  // Applica stili per il font e le dimensioni
  const fontClass = small ? 'text-xs' : 'text-sm';
  const paddingClass = small ? 'px-2 py-1' : 'px-3 py-1.5';
  
  // Classe d'accento per lo stato RUNNING/IDLE
  // Vengono usate le classi 'safelisted' (es. text-red-500)
  const dynamicClasses = {
      idleButton: `text-${accentColor}-500 border-${accentColor}-500/50`,
      runningBg: `bg-${accentColor}-600 border-${accentColor}-700`,
      finishedBg: `bg-emerald-600 border-emerald-700 shadow-emerald-900/50`,
  };

  if (originalTime === 0) {
    return <span className="text-slate-500 font-mono text-xs">{value}</span>;
  }

  return (
    <div className={`flex flex-col items-center justify-center w-full ${fontClass}`}>
      
      {/* STATO 1: IDLE */}
      {status === 'idle' && (
        <button 
          onClick={handleStart}
          className={`flex items-center gap-1 bg-slate-800 hover:bg-slate-700 border ${paddingClass} rounded-full transition-all active:scale-95 group w-full justify-center shadow-sm ${dynamicClasses.idleButton}`}
        >
          <Timer size={small ? 14 : 16} className={`group-hover:text-${accentColor}-400 transition-colors`}/>
          <span className="font-bold font-mono">{value}</span>
        </button>
      )}

      {/* STATO 2: RUNNING / PAUSED */}
      {(status === 'running' || status === 'paused') && (
        <div className={`
            flex items-center gap-1 ${paddingClass} rounded-full border w-full justify-between transition-colors shadow-md
            ${status === 'running' 
                ? `${dynamicClasses.runningBg} text-white` 
                : 'bg-slate-700 border-slate-600 text-slate-300'
            }
        `}>
          <span className="font-mono font-bold w-10 text-center tracking-wider">
            {formatTime(timeLeft)}
          </span>
          <div className="flex gap-1">
            {status === 'running' ? (
              <button onClick={handlePause} className="p-0.5 hover:text-orange-200"><Pause size={small ? 12 : 14} fill="currentColor" /></button>
            ) : (
              <button onClick={handleStart} className="p-0.5 hover:text-white"><Play size={small ? 12 : 14} fill="currentColor" /></button>
            )}
            <button onClick={handleStop} className="p-0.5 hover:text-red-400"><Square size={small ? 12 : 14} fill="currentColor" /></button>
          </div>
        </div>
      )}

      {/* STATO 3: FINISHED (Con Suono!) */}
      {status === 'finished' && (
        <button 
          onClick={handleStop}
          className={`flex items-center gap-1 ${dynamicClasses.finishedBg} hover:bg-emerald-500 text-white ${paddingClass} rounded-full w-full justify-center animate-bounce shadow-lg`}
        >
          <RotateCcw size={small ? 14 : 16} />
          <span className="font-bold">GO!</span>
        </button>
      )}

    </div>
  );
}

  }

  return <Outlet />;
};

import React, { useState, useEffect } from 'react';
import { Eye, Folder, Trash2, Pencil, MessageSquare, Info, ChevronRight, Star, ChevronDown, ChevronUp, Link, Repeat, Zap, Clock, Timer } from 'lucide-react';
import { fetchFolders } from "../../api/folders";
import { fetchWorkoutsByFolder, deleteWorkout } from "../../api/workouts";
import { fetchWorkoutLogs } from "../../api/logs";

export default function ClientMonitor({ clientId, onEdit }) {
    const [folders, setFolders] = useState([]);
    const [selectedFolder, setSelectedFolder] = useState(null);
    const [workouts, setWorkouts] = useState([]);

    const [expandedWorkouts, setExpandedWorkouts] = useState([]);
    const [expandedExercises, setExpandedExercises] = useState(new Set());

    // Dati storici
    const [logs, setLogs] = useState({});
    const [activeWeeks, setActiveWeeks] = useState({});

    useEffect(() => {
        if (clientId) loadFolders();
    }, [clientId]);

    useEffect(() => {
        if (selectedFolder) {
            fetchWorkoutsByFolder(selectedFolder).then(data => {
                setWorkouts(data);
                setExpandedWorkouts(data.map(w => w.id)); // Apri tutte le schede di default

                // Carichiamo i log
                data.forEach(w => {
                    fetchWorkoutLogs(w.id).then(workoutLogs => {
                        setLogs(prev => ({ ...prev, [w.id]: workoutLogs }));
                    });
                    setActiveWeeks(prev => ({ ...prev, [w.id]: 1 }));
                });

                // Apri il primo esercizio della prima scheda per default
                if (data.length > 0 && data[0].exercises && data[0].exercises.length > 0) {
                    setExpandedExercises(new Set([data[0].exercises[0].id]));
                } else {
                    setExpandedExercises(new Set());
                }
            });
        }
    }, [selectedFolder]);

    const loadFolders = async () => {
        const data = await fetchFolders(clientId);
        setFolders(data);
        if (data.length > 0) setSelectedFolder(data[0].id);
        else {
            setSelectedFolder(null);
            setWorkouts([]);
        }
    };

    const handleDeleteWorkout = async (workoutId, e) => {
        e.stopPropagation();
        if (!confirm("Sei sicuro di voler eliminare definitivamente questa scheda?")) return;
        await deleteWorkout(workoutId);
        setWorkouts(prev => prev.filter(w => w.id !== workoutId));
    };

    const toggleWorkout = (id) => {
        setExpandedWorkouts(prev =>
            prev.includes(id) ? prev.filter(wId => wId !== id) : [...prev, id]
        );
    };

    const toggleExercise = (id) => { 
        setExpandedExercises(prev => {
            const newSet = new Set(prev);
            if (newSet.has(id)) {
                newSet.delete(id);
            } else {
                newSet.add(id);
            }
            return newSet;
        });
    };

    const getLogEntry = (workoutId, exerciseId, week, setIdx) => {
        const wLogs = logs[workoutId] || [];
        return wLogs.find(l => l.exercise_id === exerciseId && l.week_number === week && l.set_index === setIdx) || {};
    };

    const getLogOrGhost = (workoutId, exerciseId, week, setIdx, field) => {
        for (let w = week; w >= 1; w--) {
            const entry = getLogEntry(workoutId, exerciseId, w, setIdx);
            const val = field === 'reps' ? entry.reps_done : entry.kg_done;
            if (val !== undefined && val !== null && val !== "") return val;
        }
        return ""; 
    };

    const parseSets = (ex) => {
        const splitBy = (str) => (str ? str.toString().split(" / ") : []);
        const reps = splitBy(ex.sets_reps);
        const kgs = splitBy(ex.kg_target);
        const rests = splitBy(ex.recovery);
        const trainerNotes = splitBy(ex.trainer_notes);
        const setTypes = splitBy(ex.set_types);

        return reps.map((r, i) => ({
            reps: r, kg: kgs[i] || "-", rest: rests[i] || "-",
            t_note: trainerNotes[i] || "-", type: setTypes[i] || 'normal'
        }));
    };

    const getSplitVal = (val, index) => {
        if (!val) return "-";
        const parts = val.toString().split("+");
        return parts[index] !== undefined ? parts[index] : "-"; 
    };

    const getRoundValue = (str, roundIndex) => {
        const parts = str ? str.toString().split(" / ") : [];
        return parts[roundIndex] || parts[0] || "-";
    };

    const formatDateSafe = (workout) => {
        let dateString = workout.created_at || workout.date;
        if (!dateString) return "Data N/D";
        if (dateString.includes(" ") && !dateString.includes("T")) {
            dateString = dateString.replace(" ", "T");
        }
        const d = new Date(dateString);
        return isNaN(d.getTime()) ? "Data N/D" : d.toLocaleDateString('it-IT');
    };

    return (
        <div className="space-y-6 pb-20">

            {/* HEADER MONITOR */}
            <div className="bg-slate-800 p-4 sm:p-6 rounded-xl shadow-lg border border-slate-700 flex flex-col sm:flex-row justify-between items-center gap-4">
                <div className="flex items-center gap-3 sm:gap-4 w-full sm:w-auto">
                    <div className="p-2 sm:p-3 rounded-lg bg-slate-700 text-orange-500 shadow-inner">
                        <Eye size={24} className="sm:w-7 sm:h-7" />
                    </div>
                    <div>
                        <h2 className="text-lg sm:text-xl font-bold text-white tracking-tight">Diario di Bordo</h2>
                        <p className="text-[10px] sm:text-xs text-slate-400 uppercase tracking-wider font-bold">Monitoraggio Progressi</p>

                    <Folder size={18} className="text-orange-500 ml-1 sm:ml-2 sm:w-5 sm:h-5" />
                    <select

                    >

                    <Folder size={40} className="text-slate-600 mb-2 opacity-50 sm:w-12 sm:h-12" />

import React, { useState } from 'react';
import { PenTool, Eye } from 'lucide-react';
import WorkoutCreator from './WorkoutBuilder/WorkoutCreator';
import ClientMonitor from './ClientMonitor';

export default function TrainerDashboard({ trainerId, client }) {
  // --- STATI DELL'INTERFACCIA ---
  // tab: Decide quale componente mostrare ('create' o 'monitor')
  const [tab, setTab] = useState('create');
  
  // workoutToEdit: Contiene i dati della scheda se stiamo modificando (altrimenti null)
  const [workoutToEdit, setWorkoutToEdit] = useState(null);
  
  const clientId = client.id;

  // --- GESTORI DI EVENTI (LOGICA) ---

  // 1. Chiamato dal ClientMonitor quando clicchi la "Matita"
  const handleEditRequest = (workout) => {
    setWorkoutToEdit(workout); // Carica i dati della scheda nello stato
    setTab('create');          // Sposta la visualizzazione sul Builder
  };

  // 2. Chiamato dal WorkoutCreator quando clicchi "Annulla" o finisci di salvare
  const handleEditComplete = () => {
    setWorkoutToEdit(null); // Pulisce lo stato (torna a "Nuova Scheda")
    // Opzionale: Se vuoi che dopo il salvataggio torni al Monitor, scommenta questa riga:
    // setTab('monitor'); 
  };

  // 3. Gestione manuale del click sui bottoni del menu
  const handleTabChange = (newTab) => {
    setTab(newTab);
    // Se clicco "Crea Scheda" manualmente, voglio che sia vuota, non in modifica
    if (newTab === 'create') {
      setWorkoutToEdit(null); 
    }
  };

  return (
    <div className="space-y-6">
      
      {/* --- BLOCCO MENU TAB (La barra in alto) --- */}
      <div className="bg-slate-800 p-1.5 rounded-xl shadow-lg border border-slate-700 flex gap-2">
        
        {/* BOTTONE 1: CREA / MODIFICA */}
        <button 
          onClick={() => handleTabChange('create')}
          className={`
            flex-1 py-3 px-4 rounded-lg font-bold flex items-center justify-center gap-2 transition-all duration-200
            ${tab === 'create' 
              ? 'bg-orange-500 text-white shadow-md shadow-orange-900/20' // ATTIVO: Arancione acceso
              : 'text-slate-400 hover:text-white hover:bg-slate-700'       // INATTIVO: Grigio che si illumina
            }
          `}
        >
          <PenTool size={20} /> {workoutToEdit ? 'Modifica in corso...' : 'Crea Scheda'}
        </button>

        {/* BOTTONE 2: MONITOR */}
        <button 
          onClick={() => handleTabChange('monitor')}
          className={`
            flex-1 py-3 px-4 rounded-lg font-bold flex items-center justify-center gap-2 transition-all duration-200
            ${tab === 'monitor' 
              ? 'bg-orange-500 text-white shadow-md shadow-orange-900/20' 
              : 'text-slate-400 hover:text-white hover:bg-slate-700'       
            }
          `}
        >
          <Eye size={20} /> Monitor Cliente
        </button>
      </div>

      {/* --- BLOCCO CONTENUTO (Switch tra i componenti) --- */}
      {tab === 'create' ? (
        <WorkoutCreator 
            trainerId={trainerId} 
            // Non passiamo più clientId qui, perché il nuovo Creator lo gestisce internamente o tramite initialData
            
            initialData={workoutToEdit}      // <--- CORRETTO: Passiamo i dati con il nome prop giusto
            
            onCancel={handleEditComplete}    // <--- CORRETTO: Mappiamo la funzione di reset su onCancel
            onSuccess={handleEditComplete}   // <--- CORRETTO: Mappiamo la funzione di reset su onSuccess
        />
      ) : (
        <ClientMonitor 
            clientId={clientId} 
            onEdit={handleEditRequest}       // Passiamo la funzione per avviare la modifica
        />
      )}
    </div>
  );
}

      if (clientId) loadFolders();

  };

import React, { useState } from 'react';
import { Plus, Trash2, X, FileText, Timer } from "lucide-react";

export default function ExerciseItem({ 
  ex, exIdx, onUpdateName, onRemove, onAddSet, onRemoveSet, onUpdateSet 
}) {
  const [showSetMenu, setShowSetMenu] = useState(false);

  const isSuperSet = ex.exercise_type === 'superset';

  // --- FUNZIONE SICURA PER AGGIORNARE UN CAMPO SPLITTATO ---
  const handleSplitInput = (setIdx, field, subIndex, newValue) => {
    const updatedSets = [...ex.sets];
    const updatedSet = { ...updatedSets[setIdx] };
    let parts = (updatedSet[field] || "").toString().split("+");
    while (parts.length < 2) parts.push("");
    parts[subIndex] = newValue;
    updatedSet[field] = parts.join("+");
    updatedSets[setIdx] = updatedSet;
    onUpdateSet(exIdx, setIdx, field, updatedSet[field]);
  };

  const getSplitVal = (setIdx, field, subIndex) => {
    const val = ex.sets[setIdx][field] || "";
    const parts = val.toString().split("+");
    return parts[subIndex] || "";
  };

  // --- RENDER RIGHE MULTIPLE IN MODO COMPATTO ---
  const renderSetRows = (set, setIdx) => {
    // Determina quante righe splittate mostrare
    let rows = 1;
    if (set.type === 'stripping' || set.type === 'rest_pause' || isSuperSet) rows = 2;

    return Array.from({ length: rows }).map((_, subIndex) => {
      const isSecond = subIndex === 1;
      const type = isSuperSet ? 'superset' : set.type;
      const accentColor = type === 'superset' ? 'emerald' : type === 'stripping' ? 'red' : type === 'rest_pause' ? 'blue' : 'orange';

      const repsVal = (isSuperSet || type === 'stripping' || type === 'rest_pause') ? getSplitVal(setIdx, 'reps', subIndex) : set.reps;
      const kgVal = (isSuperSet || type === 'stripping') ? getSplitVal(setIdx, 'kg', subIndex) : set.kg;
      const restVal = type === 'rest_pause' ? getSplitVal(setIdx, 'rest', subIndex) : set.rest;

      const handleRepsChange = (e) => {
        (isSuperSet || type === 'stripping' || type === 'rest_pause')
          ? handleSplitInput(setIdx, 'reps', subIndex, e.target.value)
          : onUpdateSet(exIdx, setIdx, 'reps', e.target.value);
      };
      const handleKgChange = (e) => {
        (isSuperSet || type === 'stripping')
          ? handleSplitInput(setIdx, 'kg', subIndex, e.target.value)
          : onUpdateSet(exIdx, setIdx, 'kg', e.target.value);
      };
      const handleRestChange = (e) => {
        type === 'rest_pause'
          ? handleSplitInput(setIdx, 'rest', subIndex, e.target.value)
          : onUpdateSet(exIdx, setIdx, 'rest', e.target.value);
      };

      return (
        <div key={`${setIdx}-${subIndex}`} className={`p-3 rounded-xl shadow-md border bg-slate-900 border-${accentColor}-700/50 space-y-2`}>
          <div className="flex items-center gap-3 border-b border-slate-700/50 pb-2">
            <span className="w-6 h-6 flex items-center justify-center rounded-full border bg-slate-800 text-slate-400 border-slate-600">{setIdx + 1}</span>
            <span className="text-[10px] font-bold text-slate-300 uppercase">
              {isSuperSet ? (subIndex === 0 ? ex.name : ex.second_name) : type === 'stripping' || type === 'rest_pause' ? `Giro ${subIndex+1}` : `Serie ${setIdx+1}`}
            </span>
            <span className={`text-[10px] font-bold uppercase tracking-wide border px-1.5 rounded text-${accentColor}-400 border-${accentColor}-900 bg-${accentColor}-900/20`}>
              {isSuperSet ? "Super Set" : type === 'stripping' ? "Stripping" : type === 'rest_pause' ? "Rest Pause" : "Normal"}
            </span>
          </div>


          <div className="grid grid-cols-12 gap-2 items-end pt-1">
            <div className="col-span-4 sm:col-span-3">
              <span className="text-[10px] text-slate-500 block uppercase mb-1">Reps</span>
              <input type="text" className={`w-full text-center p-2 border border-slate-600 rounded text-sm bg-slate-800 text-white focus:border-${accentColor}-500 outline-none`} 
                value={repsVal} onChange={handleRepsChange} placeholder="10" />
            </div>
            <div className="col-span-4 sm:col-span-3">
              <span className="text-[10px] text-slate-500 block uppercase mb-1">Kg</span>
              <input type="text" className={`w-full text-center p-2 border border-slate-600 rounded text-sm bg-slate-800 text-white focus:border-${accentColor}-500 outline-none`} 
                value={kgVal} onChange={handleKgChange} placeholder="50" />
            </div>
            <div className="col-span-4 sm:col-span-4 flex items-center gap-2">
              <Timer size={16} className="text-slate-500 flex-shrink-0" />
              <div className="flex-1">
                <span className="text-[10px] text-slate-500 block uppercase mb-1">Rec (Sec)</span>
                {type === 'stripping' && subIndex === 0 ? (
                  <div className="w-full text-center p-2 border border-slate-800 rounded text-sm bg-slate-800 text-slate-600 outline-none">
                    -
                  </div>
                ) : (
                  <input type="text" className={`w-full text-center p-2 border border-slate-600 rounded text-sm bg-slate-800 text-white focus:border-${accentColor}-500 outline-none`} 
                    value={restVal} onChange={handleRestChange} placeholder="90" />
                )}
              </div>
            </div>
          </div>

          <div className="col-span-12 pt-1">

            <span className="text-[10px] text-slate-500 block uppercase mb-1">Note Trainer</span>
            <div className="relative">
              <FileText size={14} className="absolute left-2 top-2.5 text-slate-500"/>
              <input type="text" className={`w-full pl-7 p-2 border border-slate-600 rounded text-sm bg-slate-800 text-white focus:border-${accentColor}-500 outline-none`} 
                value={set.note} onChange={e => onUpdateSet(exIdx, setIdx, 'note', e.target.value)} placeholder="Note per il cliente..." />
            </div>
          </div>

          <div className="flex justify-end mt-2">
            {ex.sets.length > 1 && <button onClick={() => onRemoveSet(exIdx, setIdx)} className="text-red-400 hover:text-red-300 p-2 rounded-lg bg-slate-700/50 hover:bg-red-900/30 transition-colors"><Trash2 size={16} /></button>}
          </div>
        </div>
      );
    });
  };

  return (
    <div className={`relative border rounded-xl p-3 sm:p-4 shadow-lg transition-all duration-300 ${isSuperSet ? 'bg-slate-800 border-emerald-500/50' : 'bg-slate-800 border-slate-700 hover:border-orange-500'}`}>
      {/* HEADER */}
      <div className="flex flex-col gap-3 mb-4 border-b border-slate-700 pb-3">
        <div className="flex justify-between items-start">
          <div className="flex items-center gap-3 flex-1">
            <span className={`w-7 h-7 flex items-center justify-center rounded-lg text-sm font-bold shadow-md flex-shrink-0 ${isSuperSet ? 'bg-emerald-600 text-white' : 'bg-orange-600 text-white'}`}>
              {exIdx + 1}

import React, { useState, useEffect } from 'react';

export default function WorkoutCreator({ trainerId, initialData, onCancel, onSuccess }) {
  const [loading, setLoading] = useState(false);
  
  // Se c'è initialData, siamo in MODIFICA, altrimenti NUOVA
  const isEditing = !!initialData;

  // Stato Dati Scheda
  const [title, setTitle] = useState('');
  const [cycleName, setCycleName] = useState('');
  const [selectedFolder, setSelectedFolder] = useState(null);
  const [selectedClient, setSelectedClient] = useState(null);
  
  // Stato Liste per i Dropdown
  const [clients, setClients] = useState([]);
  const [folders, setFolders] = useState([]);
  
  // Stato Esercizi
  const [exercises, setExercises] = useState([]);
  
  // Opzioni avanzate
  const [workoutType, setWorkoutType] = useState('standard'); 
  const [circuitRounds, setCircuitRounds] = useState(3);
  const [circuitRest, setCircuitRest] = useState("90\"");

  // 1. Caricamento Clienti 
  useEffect(() => {
    if (trainerId) {
        fetchClients(trainerId)
            .then(setClients)
            .catch(err => console.error("Errore caricamento clienti:", err));
    }
  }, [trainerId]);

  // 2. Caricamento Cartelle 
  useEffect(() => {
    if (selectedClient) {
        fetchFolders(selectedClient)
            .then(setFolders)
            .catch(err => console.error("Errore caricamento cartelle:", err));
    } else {
        setFolders([]); 
    }
  }, [selectedClient]);

  // 3. Caricamento Dati in caso di Modifica
  useEffect(() => {
    if (initialData) {
      setTitle(initialData.title || '');
      setCycleName(initialData.cycle_name || '');
      setSelectedClient(initialData.client_id || null);
      setSelectedFolder(initialData.folder_id || null);
      
      setWorkoutType(initialData.workout_type || 'standard');
      setCircuitRounds(initialData.circuit_rounds || 3);
      setCircuitRest(initialData.circuit_rest || "90\"");
      
      if (initialData.exercises) {
         setExercises(initialData.exercises.map(ex => ({
             ...ex,
             tempId: ex.id || Date.now() + Math.random()
         })));
      }
    }
  }, [initialData]);

  // Gestione Aggiunta Esercizio
  const addExercise = () => {
    const newEx = {
      tempId: Date.now(),
      name: '',
      second_name: '',
      exercise_type: 'normal',
      sets_reps: '',
      set_types: '', 
      recovery: '',
      kg_target: '',
      trainer_notes: ''
    };
    setExercises([...exercises, newEx]);
  };

  // Gestione Modifica Esercizio
  const updateExercise = (id, field, value) => {
    setExercises(prev => prev.map(ex => 
      (ex.id === id || ex.tempId === id) ? { ...ex, [field]: value } : ex
    ));
  };

  // Gestione Rimozione Esercizio
  const removeExercise = (id) => {
    setExercises(prev => prev.filter(ex => (ex.id !== id && ex.tempId !== id)));
  };

  // Gestione Spostamento Esercizio
  const moveExercise = (index, direction) => {
    const newExercises = [...exercises];
    if (direction === 'up' && index > 0) {
      [newExercises[index], newExercises[index - 1]] = [newExercises[index - 1], newExercises[index]];
    } else if (direction === 'down' && index < newExercises.length - 1) {
      [newExercises[index], newExercises[index + 1]] = [newExercises[index + 1], newExercises[index]];
    }
    setExercises(newExercises);
  };

  // --- SALVATAGGIO ---

        ...ex,
        exercise_order: i,
        id: asNew ? null : ex.id 
      }))
    };

      if (isEditing && !asNew) {
        await updateWorkout(initialData.id, payload);
      } else {
        await createWorkout(payload);
      }
      onSuccess(); 
    } catch (error) {
      console.error("Errore salvataggio:", error);
      alert("Errore durante il salvataggio.");
    } finally {
      setLoading(false);
    }
  };

  return (

    setCycleName,
    durationWeeks, 
    setDurationWeeks, 
    isEditMode
}) {

  // Funzione che gestisce l'aggiornamento della durata, garantendo che sia un numero intero
  const handleDurationChange = (e) => {
    // Il valore è già convertito a intero nell'onChange del select sottostante
    // Ma usiamo Math.min/max per limitare l'input visivo tra 1 e 6, anche se il select lo fa già
    const val = parseInt(e.target.value);
    setDurationWeeks(Math.min(Math.max(1, val), 6));
  }

  return (
    // --- CONTENITORE PRINCIPALE (Dark Mode) ---
    <div className="grid grid-cols-1 md:grid-cols-2 gap-6 bg-slate-800 p-6 rounded-xl border border-slate-700 shadow-lg">
        
        {/* Lato Sinistro: Cartelle */}
        <div>
            <label className="text-xs font-bold text-orange-500 uppercase block mb-2 tracking-wide">Cartella</label>
            
            {isCreatingFolder ? (
                // MODALITÀ CREAZIONE
                <div className="flex items-center gap-2 bg-slate-900 border border-orange-500 rounded-lg p-1 shadow-sm">
                    <input
                        type="text"
                        placeholder="Nome cartella..."
                        className="flex-1 p-1.5 bg-transparent outline-none text-sm text-white font-medium placeholder-slate-500"
                        value={newFolderName}
                        onChange={e => setNewFolderName(e.target.value)}
                        autoFocus
                    />
                    <button onClick={onCreateFolder} className="text-slate-900 bg-emerald-500 hover:bg-emerald-400 p-1.5 rounded-md transition-all">
                        <Check size={16} />
                    </button>
                    <button onClick={() => { setIsCreatingFolder(false); setNewFolderName(""); }} className="text-slate-400 hover:text-red-400 p-1.5 hover:bg-slate-800 rounded-md transition-all">
                        <X size={16} />
                    </button>
                </div>
            ) : (
                // MODALITÀ SELEZIONE
                <div className="flex items-center gap-2 bg-slate-900 border border-slate-600 rounded-lg p-1.5 hover:border-orange-500 transition-colors">
                  <select
                      className="flex-1 p-1 bg-transparent outline-none text-sm font-medium text-white cursor-pointer"
                      value={selectedFolder || ""}
                      onChange={e => setSelectedFolder(parseInt(e.target.value))}
                  >
                      {folders.map(f => <option key={f.id} value={f.id} className="bg-slate-700 text-white">{f.name}</option>)}
                  </select>
                  
                  {/* Tasto Elimina */}
                  {selectedFolder && folders.length > 0 && !isEditMode && (
                    <button onClick={onDeleteFolder} className="text-slate-500 hover:text-red-500 p-1.5 transition-colors" title="Elimina cartella">
                      <Trash2 size={16} />
                    </button>
                  )}

                  {/* Tasto Nuova Cartella */}
                  {!isEditMode && (
                      <button 
                        onClick={() => setIsCreatingFolder(true)} 
                        className="text-slate-900 bg-orange-500 hover:bg-orange-400 p-1.5 transition-all rounded-md shadow-sm"
                        title="Nuova Cartella"
                      >
                        <Plus size={16} />
                      </button>
                  )}
                </div>
            )}
        </div>

        {/* Lato Destro: Dati Scheda */}
        <div className="flex flex-col gap-4">
            <div>
                <label className="text-xs font-bold text-orange-500 uppercase block mb-2 tracking-wide">Nome Scheda</label>
                <input
                    type="text"
                    className="w-full border border-slate-600 p-2.5 rounded-lg font-bold text-lg outline-none text-white focus:border-orange-500 focus:ring-1 focus:ring-orange-500 transition-all bg-slate-900 placeholder-slate-600"
                    value={title}
                    onChange={e => setTitle(e.target.value)}
                    placeholder="Es. Pull A"
                />
            </div>
            
            {/* RIGA MISTA: Tipologia + Durata */}
            <div className="flex gap-4">
                
                {/* Tipologia / Ciclo */}
                <div className="flex-1">
                    <label className="text-xs font-bold text-orange-500 uppercase block mb-2 tracking-wide">Tipologia</label>
                    <input
                        type="text"
                        className="w-full border border-slate-600 p-2.5 rounded-lg text-sm outline-none focus:border-orange-500 focus:ring-1 focus:ring-orange-500 transition-all bg-slate-900 text-white placeholder-slate-600"
                        value={cycleName}
                        onChange={e => setCycleName(e.target.value)}
                        placeholder="Es. Upper"
                    />
                </div>

                {/* NUOVO: Selettore Durata (Settimane) */}
                <div className="w-1/3">
                    <label className="text-xs font-bold text-orange-500 uppercase block mb-2 tracking-wide">Settimane</label>
                    {/* La prop è già gestita con parseInt nella onChange sottostante */}
                    <select 
                        className="w-full border border-slate-600 p-2.5 rounded-lg text-sm outline-none focus:border-orange-500 focus:ring-1 focus:ring-orange-500 transition-all bg-slate-900 text-white cursor-pointer"
                        value={durationWeeks}
                        onChange={handleDurationChange} // <--- CHIAMIAMO LA NOSTRA FUNZIONE WRAPPER
                    >
                        {[1, 2, 3, 4, 5, 6].map(num => (
                            <option key={num} value={num} className="bg-slate-700">{num}</option>
                        ))}
                    </select>
                </div>
            </div>
        </div>
      </div>
  );
}
